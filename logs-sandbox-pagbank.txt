3) WEBHOOK / NOTIFICACAO (API de Notificacao)
=====================================================
Fluxo do servidor em producao:
  1. PagBank envia POST com { "id": "<order_id>" } e header x-authenticity-token;
  2. Servidor valida a assinatura SHA-256 (comparacao em tempo constante);
  3. Servidor consulta a ordem na API autenticada (GET /orders/{id});
  4. Confere status PAID e valor (1990 = R$ 19,90);
  5. Ativa o Premium de forma idempotente e responde 200 OK.
