HOMOLOGACAO PAGBANK - LIBIDO (www.libidoapp.com.br)
Integracao: API de Pedidos e Pagamentos (Order) com PIX + Webhook (API de Notificacao)

=====================================================
1) CRIACAO DO PEDIDO PIX
=====================================================
POST https://api.pagseguro.com/orders
Headers:
  Authorization: Bearer ***TOKEN_MASCARADO_POR_SEGURANCA***
  Content-Type: application/json

Request:
{
  "reference_id": "libido-premium_5f3a9b2c_local1",
  "customer": {
    "name": "Usuario Teste",
    "email": "usuario.teste@example.com",
    "tax_id": "12345678909"
  },
  "items": [
    {
      "name": "Libido Premium - Acesso 24 horas",
      "quantity": 1,
      "unit_amount": 1990
    }
  ],
  "qr_codes": [
    { "amount": { "value": 1990 } }
  ]
}

Response (200 OK):
{
  "id": "ORD-EXEMPLO-123456",
  "reference_id": "libido-premium_5f3a9b2c_local1",
  "status": "WAITING",
  "qr_codes": [
    {
      "id": "QR-EXEMPLO-001",
      "txid": "txid_exemplo_pagbank",
      "links": [
        { "media": "image/png", "href": "https://stc.pagseguro.uol.com.br/qrcode/..." }
      ]
    }
  ]
}

=====================================================
2) CONSULTA DA ORDEM (executada apos receber a notificacao)
=====================================================
GET https://api.pagseguro.com/orders/ORD-EXEMPLO-123456
Headers:
  Authorization: Bearer ***TOKEN_MASCARADO_POR_SEGURANCA***

Response (200 OK):
{
  "id": "ORD-EXEMPLO-123456",
  "reference_id": "libido-premium_5f3a9b2c_local1",
  "status": "PAID",
  "charges": [
    {
      "status": "PAID",
      "amount": { "value": 1990 }
    }
  ]
}

=====================================================
3) WEBHOOK / NOTIFICACAO
=====================================================
O PagBank envia um POST para a URL de notificacao registrada:

Headers:
  x-authenticity-token: <assinatura SHA-256 gerada com o token + corpo da requisicao>

Request body:
{ "id": "ORD-EXEMPLO-123456" }

Fluxo do nosso servidor:
  1. Valida a assinatura (SHA-256, comparacao em tempo constante);
  2. Consulta a ordem diretamente na API autenticada do PagBank;
  3. Confere o status PAID e o valor (1990 = R$ 19,90);
  4. Ativa o Premium de forma idempotente (pagamento duplicado nao reativa);
  5. Responde 200 OK ao PagBank.
